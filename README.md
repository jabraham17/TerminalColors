# TerminalColors

TerminalColors is a library for working with terminal colors in Chapel. It provides a simple interface for setting foreground and background colors, as well as text attributes like bold and underline.

## Installation

Add TerminalColors as a Mason dependency:

```bash
mason add TerminalColors@0.1.0
```
